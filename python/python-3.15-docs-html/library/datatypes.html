Tipos de Dados¶

Os módulos descritos neste capítulo fornecem uma variedade de tipos de dados especializados, como datas e horas, vetores de tipo fixo, filas de heap, filas de extremidade dupla e enumerações.

O Python também fornece alguns tipos de dados embutidos, em especial list, tuple, dict, frozendict, set e frozenset. A classe str é usada para armazenar strings Unicode, e as classes bytes e bytearray são usadas para armazenar dados binários.
