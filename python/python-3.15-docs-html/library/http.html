http — Módulos HTTP¶

Código-fonte: Lib/http/__init__.py

http é um pacote que agrupa vários módulos para trabalhar com o Protocolo de Transferência de Hipertexto:

  • http.client é um cliente de protocolo HTTP de baixo nível; para abertura de URL de alto nível, use urllib.request

  • http.server contém classes básicas de servidor HTTP baseadas em socketserver

  • http.cookies tem utilitários para implementar gerenciamento de estado com cookies

  • http.cookiejar provê persistência de cookies

O módulo http também define as seguintes enumerações que podem ajudar você a trabalhar com os códigos relacionados ao HTTP:

class http.HTTPStatus¶

Adicionado na versão 3.5.

Subclasse de enum.IntEnum que define um conjunto de códigos de estado HTTP, frases de razão e descrições longas em inglês.

Uso:

>>> from http import HTTPStatus
>>> HTTPStatus.OK
HTTPStatus.OK
>>> HTTPStatus.OK == 200
True
>>> HTTPStatus.OK.value
200
>>> HTTPStatus.OK.phrase
'OK'
>>> HTTPStatus.OK.description
'Request fulfilled, document follows'
>>> list(HTTPStatus)
[HTTPStatus.CONTINUE, HTTPStatus.SWITCHING_PROTOCOLS, ...]

Para preservar a retrocompatibilidade, os valores de enumerações também estão presentes no módulo http.client na forma de constantes. O nome da enumeração é igual ao da constante (i.e., http.HTTPStatus.OK também está disponível como http.client.OK).

Alterado na versão 3.7: Adicionado código de estado 421 MISDIRECTED_REQUEST.

Adicionado na versão 3.8: Adicionado código de estado 451 UNAVAILABLE_FOR_LEGAL_REASONS.

Adicionado na versão 3.9: Adicionado os códigos de estado 103 EARLY_HINTS, 418 IM_A_TEAPOT e 425 TOO_EARLY.

Alterado na versão 3.13: Implementada a nomenclatura do RFC9110 para constantes de estado. Os nomes antigos das constantes foram mantidos para retrocompatibilidade: 413 REQUEST_ENTITY_TOO_LARGE, 414 REQUEST_URI_TOO_LONG, 416 REQUESTED_RANGE_NOT_SATISFIABLE e 422 UNPROCESSABLE_ENTITY.

Categoria de estado HTTP¶

Adicionado na versão 3.12.

Os valores das enumerações possuem várias propriedades que indicam a categoria do estado HTTP.

Propriedade

Indica que

Detalhes (em inglês)

is_informational

100 <= estado <= 199

HTTP Semantics RFC 9110, Seção 15

is_success

200 <= estado <= 299

HTTP Semantics RFC 9110, Seção 15

is_redirection

300 <= estado <= 399

HTTP Semantics RFC 9110, Seção 15

is_client_error

400 <= estado <= 499

HTTP Semantics RFC 9110, Seção 15

is_server_error

500 <= estado <= 599

HTTP Semantics RFC 9110, Seção 15

Uso:

>>> from http import HTTPStatus
>>> HTTPStatus.OK.is_success
True
>>> HTTPStatus.OK.is_client_error
False
class http.HTTPMethod¶

Adicionado na versão 3.11.

Subclasse de enum.StrEnum que define um conjunto de métodos HTTP e suas respectivas descrições em inglês.

Uso:

>>> from http import HTTPMethod
>>>
>>> HTTPMethod.GET
<HTTPMethod.GET>
>>> HTTPMethod.GET == 'GET'
True
>>> HTTPMethod.GET.value
'GET'
>>> HTTPMethod.GET.description
'Retrieve the target.'
>>> list(HTTPMethod)
[<HTTPMethod.CONNECT>,
 <HTTPMethod.DELETE>,
 <HTTPMethod.GET>,
 <HTTPMethod.HEAD>,
 <HTTPMethod.OPTIONS>,
 <HTTPMethod.PATCH>,
 <HTTPMethod.POST>,
 <HTTPMethod.PUT>,
 <HTTPMethod.TRACE>]
