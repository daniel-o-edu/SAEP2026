Os documentos deste repositório foram todos validados.
Eles servem como documentação técnica para utilização na prova prática do SAEP 2026.

Para baixar os arquivos e trabalhar no seu computador, siga as instruções abaixo:

1. Abra o terminal: No Windows CMD ou PowerShell.
2. Escolha a pasta: Navegue até a pasta onde deseja salvar o projeto usando o comando `cd`.
3. Clone o repositório: Digite o comando abaixo e pressione Enter:

   `git clone https://github.com/daniel-o-edu/SAEP2026`

4. Acesse a pasta: Entre na pasta criada digitando: `cd SAEP2026`
   
Agora você já pode acessar todos os materiais das aulas que serão atualizados semanalmente!
